# Luxury Dark Cyber-Wine Portfolio & Contact System

A modern, fully responsive personal portfolio website featuring a luxury dark cyber-wine aesthetic, custom hardware-accelerated animations, theme toggling, and an integrated backend mail system.

## 🚀 Features
* **Design System:** Custom CSS design tokens featuring a luxury dark burgundy and gold theme with high-contrast text readability.
* **Interactive Elements:** Custom JavaScript cursor, scroll-reveal animations, and dynamic UI components.
* **Backend Integration:** Node.js & Express server equipped with Nodemailer for handling contact form submissions securely.
* **Theme Support:** Fully adaptive dark and light mode toggle.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Variables / Glassmorphism), JavaScript (ES6+)
* **Backend:** Node.js, Express.js, Nodemailer
* **Fonts & Icons:** Google Fonts (Syne, Plus Jakarta Sans, JetBrains Mono)
